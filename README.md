# Sorpresa para Isa 💜

Una pequeña experiencia interactiva de cumpleaños hecha con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura y contenido de la web.
- `style.css`: diseño adaptable, estrellas y animaciones.
- `script.js`: navegación, pista de fecha y revelación del regalo.

## Añadir fotos
Sube dos imágenes a la raíz del repositorio y llámalas exactamente:
- `recuerdo-1.jpg`
- `recuerdo-2.jpg`

La página las buscará con esos nombres. Si las fotos son privadas o íntimas, no las subas a un repositorio público.

## Publicar con GitHub Pages
1. Abre **Settings** en este repositorio.
2. En el menú lateral, entra en **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)), y pulsa **Save**.
5. Espera a que termine la publicación. GitHub mostrará el enlace en esa misma sección.

## Nota de privacidad
La fecha de cumpleaños es una pista para la experiencia, no una protección real. El código de una web estática pública se puede inspeccionar. No incluyas información sensible.
